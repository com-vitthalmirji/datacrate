# M1 — Rust core, due 24 August 2026

## Outcome

Build a `csv-select` binary and deliver a 15-minute ownership explanation
without notes. Keep the existing fundamentals demo runnable.

## CLI contract

```console
csv-select <INPUT> --column <ZERO_BASED_INDEX> [--no-headers]
```

- Read CSV records incrementally; do not load the complete file.
- Default: treat the first record as headers and emit the selected header.
- `--no-headers`: treat the first record as data and emit no header.
- Write through `csv::Writer`, never by joining strings.
- Reject an invalid column before writing any output.
- Return a non-zero status and useful stderr for bad arguments, missing input,
  malformed CSV, and invalid columns.
- Use no `unwrap()` or `expect()` on user-controlled input.

Fixtures and expected output are under [`../fixtures/m1`](../fixtures/m1).
